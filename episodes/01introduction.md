## Our Scenario and pipeline

In this lesson, we will combine teaching the basic elements of Quarto with the process of writing and publishing a scientific article.

To do so, we will create a fictional paper focused on the distribution of different media of art in the Museum of Modern Art (MoMA).

We will begin after we have finished our research and are about to start writing the paper. To do this, we need to go through several steps — all of which must be completed before we can move on.

We have already started by installing Quarto and our preferred coding environment on our computer. For this, we chose Visual Studio Code.

Now, we need to actually start writing the paper in Quarto.

To do so, we will first create our project folder and document. This will be done through the “Getting Started” episode.

Then, we want to begin writing our text. We quickly notice that we need to learn the basics of the “Markdown” language, which Quarto uses to create text and formatting. This will be covered throughout our “Markdown Basics” episode.

After using our newly gained Markdown knowledge to structure and write the text of our paper, we need to enrich it with the necessary metadata — which is then used to generate a header and front page. To do this, we will need another language used in Quarto: YAML. This will all be shown in our “An Introduction to YAML Headers” episode.

We are halfway done with our paper. Now that we have a structured text enriched with metadata, we want to spruce it up with a few relevant and visually pleasing illustrations and graphs. This can be done using Quarto’s integrated visual coding languages, such as Mermaid or Graphviz. To do so, we will walk through the steps in the next episode: “Creating and Implementing Code for Visualizations.”

Now we are almost done. There are only a few more steps to complete. First, we want to decide whether we want our paper published as a PDF or as an HTML document. The unique options available for these formats will be discussed in the short episode “Quarto for PDF and HTML.”

For our paper to be considered academically rigorous, we naturally need to provide an abundant amount of sources in the form of footnotes, references, and a solid bibliography. Thankfully, Quarto offers a nice, easy-to-understand integrated bibliography feature, which we will use to enrich our paper with sources. This will be demonstrated and implemented throughout our episode “Using the Bibliography.”

Finally, we are finished with our paper! But now, the option to create a complementary website — on which we present our findings — sounds very enticing. So we will do so using the options Quarto provides. This will be done in our final episode: “Creating a simple Website with Quarto.”

::: caution
Of course, all of these options are available to you at any point. When using Quarto to publish, you can freely combine all these functions and steps to create your own workflow!
